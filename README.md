# 50×60 Residential House Plan | AutoCAD 2D Drafting

## Project Overview
This project is a 2D residential house and site plan drafted using AutoCAD. It represents a proposed single-storey 2BHK residence within a 50 ft × 60 ft plot, with road access along the 50 ft frontage.

The drawing focuses on architectural floor planning, wall layout, room arrangement, door and window placement, and site organization.

## Project Details
- **Project Type:** Residential House Plan
- **Plot Size:** 50 ft × 60 ft
- **Building Type:** Single-Storey 2BHK Residence
- **Software:** AutoCAD
- **Drawing Type:** 2D Architectural Drafting
- **Drawing Units:** Engineering (Feet and Inches)
- **Drawing Scale:** 1:1

## Spaces Included
- Two bedrooms
- Bathroom
- Vestibule
- Kitchen
- Open dining area
- Living room
- Entry and foyer
- Front garden and access pathway
- Compound wall and vehicular gate

## Drafting Specifications
- External wall thickness: 9 inches
- Internal partition thickness: 4.5 inches
- Main entrance door: 3 ft 6 in
- Bedroom doors: 3 ft
- Bathroom door: 2 ft 6 in
- Door swings and window openings represented in the plan

## Skills Practiced
- 2D architectural drafting
- Residential space planning
- Wall layout and room partitioning
- Door and window placement
- Dimensioning and annotation
- AutoCAD layers and drawing organization
- Site planning and furniture arrangement
